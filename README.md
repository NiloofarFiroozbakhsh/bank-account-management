# bank-account-management

A Java program that models checking and savings accounts using object-oriented programming.

## Features
- Create checking and savings accounts
- Perform basic account operations
- Use shared behavior across account types
- Apply different behavior depending on the account type

## Technologies and Concepts
- Java
- Object-Oriented Programming
- Inheritance
- Polymorphism

## What I Learned
This project helped me practice organizing related classes and using inheritance and polymorphism to manage shared and account-specific behavior.
